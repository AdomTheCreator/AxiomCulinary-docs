# AxiomCulinary documentation

**[Read the AxiomCulinary Wiki](https://github.com/AdomTheCreator/AxiomCulinary-docs/wiki)** — installation, farming, cooking and server administration.

Grow ingredients, prepare food at physical workstations and improve meals through cooking. AxiomCulinary is part of the **Axiom** suite.

This public repository contains documentation only. Plugin source code and JAR files remain private; no plugin download is published here. Current documentation targets **0.13.0-SNAPSHOT**, Paper 26.3 and Java 25.

## Current content

13 crops, 32 stations and 69 processing recipes. Built-in models require no client resource pack. Nexo, CraftEngine and WorldGuard are optional integrations; see [Compatibility](docs/Compatibility.md) for verified combinations and limits.

Documentation describes the development snapshot and may change before release. Distribution terms for the plugin are separate from this documentation.
